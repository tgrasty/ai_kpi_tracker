# Automated KPI Tracker

A lightweight Streamlit dashboard that tracks key performance metrics and generates AI-powered summaries.

### 🧭 Overview
This project demonstrates how data teams can automate KPI reporting using Python, Streamlit, and an AI assistant. The app calculates metrics like revenue growth and churn, visualizes trends, and creates executive summaries automatically.

### 🛠️ Tech Stack
- Python (pandas, plotly, streamlit)
- OpenAI API for natural language summaries
- CSV or API data sources

### 🎯 Relevance
Built to showcase how Technical Program Managers can prototype data-driven automation for analytics and reporting workflows.
